# Отправка сообщений с шаблонными кнопками

{% hint style="info" %}
Данный функционал работает в бета-режиме.&#x20;

Функции могут быть изменены, а их работа может быть нестабильна.
{% endhint %}

Помимо отправки сообщений с кнопками, позволяющими выбрать пользователю готовый вариант ответа, функционал OLChat позволяет отправлять сообщения с шаблонными кнопками, не требующими ответа, а несущими справочную, либо иную другую полезную информацию.

Например, отправка сообщения с шаблонными кнопками, позволяющими предоставить промокод, кнопку для перехода в чат со специалистом, кнопку для автоматического набора номера телефона  компании.&#x20;

### Настройка робота

Чтобы отравлять сообщения с шаблонными кнопками, добавьте робота «\[OLChat] - Отправка сообщения с шаблонными кнопками». Для этого перейдите в раздел "Роботы", далее:

1. Нажмите кнопку "Создать".
2. Выберите стадию, на которую необходимо добавить робота.
3. Из меню рубрик выберите "Другие роботы".
4. Выберите «\[OLChat] - Отправка сообщения с шаблонными кнопками».
