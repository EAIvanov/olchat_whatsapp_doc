# Copy of Страница просмотра статусов рассылок CRM-маркетинга

На странице статусов рассылок можно проверить отправленные сообщения WhatsApp, их текущий статус, получателя, текст сообщения и линию, через которую выполнялась отправка.

Чтобы зайти на страницу просмотра статусов рассылок CRM-маркетинга, в левом меню портала перейдите в приложение Олча&#x442;**.** В открывшемся окне выберите пункт меню **Рассылки**.

<figure><img src="../../.gitbook/assets/image (610).png" alt=""><figcaption></figcaption></figure>

## Просмотр статусов сообщений

Для каждого сообщения на странице отображаются:

* **Линия** — линия, через которую было отправлено сообщение.
* **Отправлено** — дата и время отправки.
* **Получатель** — номер телефона получателя.
* **Сообщение** — текст отправленного сообщения.
* **Статус** — текущий статус сообщения.

Для сообщений могут отображаться следующие статусы:

* **Не отправлено** — сообщение не было отправлено.
* **Доставлено** — сообщение доставлено получателю.
* **Прочитано** — получатель прочитал сообщение.
* **Получен ответ** — от получателя поступил ответ на сообщение.

<figure><img src="../../.gitbook/assets/image (615).png" alt=""><figcaption></figcaption></figure>

## Фильтрация рассылок

Список сообщений можно отфильтровать с помощью фильтров.

Например, если подключено несколько линий WhatsApp, можно вывести сообщения только для нужной линии.

Также на странице доступны фильтры по другим столбцам, для которых отображается значок фильтра.

<figure><img src="../../.gitbook/assets/image (618).png" alt=""><figcaption></figcaption></figure>

## Поиск

Введите в строку поиска номер или текст сообщения и нажмите на 🔍.

## Экспорт данных

Чтобы выгрузить информацию о рассылках, нажмите **Экспорт**.

<figure><img src="../../.gitbook/assets/image (625).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Страница просмотра статусов рассылок CRM-маркетинга содержит данные о рассылках за последние 6 месяцев.
{% endhint %}

## Очередь сообщений

Чтобы посмотреть сообщения, которые ожидают отправки, нажмите **Очередь сообщений** в правой верхней части страницы.

В очереди можно остановить дальнейшую отправку сообщений. Для этого нажмите **Очистить очередь**.

После очистки сообщения, которые ещё находятся в очереди и не были отправлены, будут удалены из неё. Их отправка получателям будет прекращена.

Очистка очереди не влияет на сообщения, которые уже были отправлены.

## Статус рассылок, отправленных через роботов или бизнес-процессы

Чтобы сообщения, отправленные с помощью роботов или бизнес-процессов, отображались на странице статусов рассылок CRM-маркетинга, в параметре **Выбор очереди отправки** выберите **Очередь рассылки**.

<figure><img src="../../.gitbook/assets/image (1425).png" alt=""><figcaption></figcaption></figure>

В этом случае Олчат добавляет сообщение в общую очередь рассылки. Информацию о его отправке и текущем статусе можно посмотреть на странице **Рассылки**.

Если выбрать **Очередь сообщений**, такая отправка не отображается на странице просмотра статусов рассылок CRM-маркетинга.
