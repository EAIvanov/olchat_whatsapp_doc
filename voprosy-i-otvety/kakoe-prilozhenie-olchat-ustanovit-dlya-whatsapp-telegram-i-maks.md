# Какое приложение Олчат установить для WhatsApp, Telegram и МАКС?

Сейчас для подключения каналов используются несколько приложений Олчат:

* Олчат WhatsApp — для подключения WhatsApp.
* Олчат Telegram — для подключения Telegram.
* Олчат ОМНИ — для подключения МАКС. В нём также доступна новая интеграция с Telegram.

Раньше WhatsApp и Telegram работали в отдельных приложениях. Сейчас мы развиваем Олчат ОМНИ — общее приложение, в котором планируем объединить все каналы. Первой новой интеграцией в нём стал МАКС, вместе с ним появилась и новая версия Telegram.

## **Каким приложением пользоваться для Telegram**

Telegram можно подключить через Олчат Telegram или Олчат ОМНИ.

Пока рекомендуем использовать отдельное приложение Олчат Telegram — оно работает стабильнее, его функциональность лучше отработана. Если Telegram уже подключён через это приложение, переносить его в Олчат ОМНИ не нужно.

Интеграция с Telegram в Олчат ОМНИ тоже работает, но её доработка ещё продолжается.

## **Зачем устанавливать Олчат ОМНИ**

Олчат ОМНИ нужно установить, чтобы подключить МАКС. В дальнейшем это приложение станет единым для всех интеграций, и управлять ими можно будет в одном месте.

Пока переход идёт постепенно, поэтому для WhatsApp, Telegram и МАКС используются разные приложения. Конкретные сроки полного объединения пока не определены.
