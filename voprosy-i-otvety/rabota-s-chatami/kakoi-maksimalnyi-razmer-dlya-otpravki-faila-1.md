# Copy of Какой максимальный размер для отправки файла?

Максимальный размер файла для отправки через Открытые линии — **100 МБ**.

Ограничение действует как при отправке файлов непосредственно из чата Открытой линии, так и при использовании робота **Отправка файла**.

Файлы размером более 100 МБ не отправляются.
