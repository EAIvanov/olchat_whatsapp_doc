# Установка приложения

Установка приложения осуществляется через **Битрикс24 Маркетплейс.** Для установки OLChat выполните следующие действия:

{% stepper %}
{% step %}
#### Перейдите в Маркетплейс из верхнего меню или меню слева портала Битрикс24.

<figure><img src="../.gitbook/assets/image (1436).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (1437).png" alt=""><figcaption></figcaption></figure>


{% endstep %}

{% step %}
#### В поисковой строке введите "OLChat".

<figure><img src="../.gitbook/assets/2024-12-12_17-39-36.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Выберите "OLChat — Чаты и Группы WhatsApp".

<figure><img src="../.gitbook/assets/image (1438).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Выполните установку приложения на портал, нажав кнопку "Установить".

<figure><img src="../.gitbook/assets/image (1434).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Установка завершена. Приложение OLChat появилось в меню слева на вашем портале Битрикс24.

При первом запуске приложения и до момента заполнения данных в приложении будет открываться окно "Контактные данные":

<figure><img src="../.gitbook/assets/image (1439).png" alt=""><figcaption></figcaption></figure>

Заполните все поля, указав фамилию, имя и отчество, телефон и e-mail для связи с сотрудником, который отвечает за настройку приложения OLChat, а также подтвердите согласие на обработку персональных данных, проставив галочку в соответствующей строке.&#x20;

Данную информацию можно изменить в настройках приложения. Для того, чтобы это сделать, выполните следующие действия:

1. В меню слева в приложении OLChat выберите "Настройки приложения".
2. В меню настроек выберите пункт "Контакты и уведомления".
3. Обновите данные и нажмите кнопку "Сохранить".

<figure><img src="../.gitbook/assets/image (1440).png" alt=""><figcaption></figcaption></figure>




{% endstep %}
{% endstepper %}

Выполните установку приложения, нажав на кнопку «УСТАНОВИТЬ».

{% hint style="info" %}
Установить приложение OLChat без поиска в Маркетплейсе можно, перейдя по [ссылке](https://www.bitrix24.ru/apps/app/infocom.olchat/?p=132277).
{% endhint %}
