# Тарифы приложения

### Бесплатный пробный период 3 дня <a href="#besplatnyi-demo-period-3-dnya" id="besplatnyi-demo-period-3-dnya"></a>

После установки приложения вам сразу доступно подключение бесплатного демонстрационного периода. Для этого нужно только [Подключение открытой линии и коннектора](https://docs.olchat.io/ustanovka-i-nastroika/podklyuchenie-konnektora).

Пробный период активируется автоматически.

{% hint style="success" %}
Вы можете самостоятельно подключить только 2 линии. Если вам необходимо больше, то обратитесь в [чат поддержки](https://auth2.bitrix24.net/oauth/select/?preset=im\&IM_DIALOG=networkLines7c380c91ab28dacab02d3af93fecdbf9).
{% endhint %}

### Стоимость коннектора (приложения, линии, номера) <a href="#stoimost-konnektora-prilozheniya-linii-nomera" id="stoimost-konnektora-prilozheniya-linii-nomera"></a>

У нас один тариф стоимостью **3 600 рублей** за одну подключённую открытую линию (аккаунт WhatsApp) на 30 дней.

{% hint style="warning" %}
Временно оплачивать сервис картами, выпущенными НЕ на территории России, нельзя. Для оплаты из других регионов напишите нам в поддержку или обратитесь к вашему интегратору. На текущий момент стоимость для других стран за 30 дней составляет:

* Казахстан — 25 000 тенге.
* Оплата в долларах — 45 долларов.
* Оплата в евро — 45 евро.
{% endhint %}

{% hint style="info" %}
К одной линии одновременно вы можете подключить только один аккаунт (номер) WhatsApp. При этом вы в любой момент можете заменить номер на другой.
{% endhint %}

{% hint style="success" %}
Оплачивать линию повторно можно в любое время. Новый оплаченный период плюсуется к оставшимся дням.
{% endhint %}

### Стоимость подключения групп WhatsApp <a href="#stoimost-podklyucheniya-grupp-whatsapp" id="stoimost-podklyucheniya-grupp-whatsapp"></a>

Мы разработали функционал интеграции групп WhatsApp с групповыми чатами Битрикс24. Это отдельный функционал, который оплачивается отдельно, в зависимости от количества подключённых групп.

{% hint style="warning" %}
### Тарифы на подключение групп:

* **50** групп для тестирования — бесплатно (с другими тарифами не суммируется)
* **150** групп на 30 дней — 3 000 руб.
* **Безлимит** групп на 30 дней — 5 000 руб.

Казахстан:

* **150** групп на 30 дней — 25 000 тенге.
* **Безлимит** групп на 30 дней — 33 000 тенге.

**Внимание!** Группы работают только при активном коннекторе (аккаунте WhatsApp). Указано общее количество групп, которое можно использовать на всех коннекторах.
{% endhint %}

{% hint style="info" %}
Подробная инструкция о том, как оплатить коннектор и группы WhatsApp содержится в статьях [Оплата коннектора](https://docs.olchat.io/stoimost-i-oplata-prilozheniya/oplata-konnektora) и [Оплата групп WhatsApp](https://docs.olchat.io/stoimost-i-oplata-prilozheniya/oplata-grupp-whatsapp).
{% endhint %}
