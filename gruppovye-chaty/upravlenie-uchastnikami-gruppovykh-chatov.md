# Управление участниками групповых чатов

В Олчат WhatsApp управлять участниками групповых чатов можно двумя способами:

* Через интерфейс приложения.
* С помощью специальных команд бота непосредственно в групповом чате.

### Управление через интерфейс приложения

Через интерфейс Олчат WhatsApp можно выполнять следующие действия с участниками группы:

* Добавлять новые контакты в группу.
* Удалять контакты из группы.
* Назначать участников администраторами.
* Снимать с участников права администратора.

<figure><img src="../.gitbook/assets/image (936).png" alt=""><figcaption></figcaption></figure>

Чтобы выполнять действия с участниками, необходимо обладать правами администратора в соответствующей группе.

Если вы открываете приложение из карточки лида или сделки, участник группы должен быть прикреплён к этой карточке в качестве контакта.

#### Как управлять участниками

1. Откройте приложение Олчат WhatsApp и перейдите к управлению групповыми чатами.
2.  Выберите действие, которое хотите выполнить.<br>

    <figure><img src="../.gitbook/assets/image (1191).png" alt=""><figcaption></figcaption></figure>
3. Выберите нужную группу из списка подключённых групп.
4. Выберите контакт, с которым необходимо выполнить действие.
5.  Нажмите **ВЫПОЛНИТЬ**.<br>

    <figure><img src="../.gitbook/assets/image (1354).png" alt=""><figcaption></figcaption></figure>

### Управление с помощью команд в чате

Для добавления и удаления сотрудников портала Битрикс24, а также пользователей WhatsApp можно использовать специальные команды бота.

#### Доступные команды

Доступны следующие команды:

1. **/remove\_bitrix\_user @Упоминание пользователя** – удаляет сотрудника портала из чата.
2. **/add\_bitrix\_user @Упоминание пользователя** – добавляет сотрудника портала в чат.
3. **/remove\_whatsapp\_user Номер пользователя** – удаляет номер из группы WhatsApp.
4. **/add\_whatsapp\_user Номер пользователя** – добавляет номер в группу WhatsApp.

Чтобы воспользоваться этой возможностью, перейдите в групповой чат и введите нужную команду. Укажите сотрудника, которого нужно пригласить или исключить из чата.
