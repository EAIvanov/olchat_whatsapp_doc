# Отправка геометки в группу

Робот «**\[OLChat] \[Группы] Отправить геометку в группу**» позволяет создавать автоматизированные сценарии для отправки точки на карте в подключенные группы при переходе лида или сделки в определённый статус. Для добавления робота необходимо:

{% stepper %}
{% step %}
**Перейти в раздел "Роботы" из списка лидов, либо карточки лида в CRM.**

<figure><img src="../../.gitbook/assets/Скриншот 27.08.25_18.03.16.png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/Скриншот 27.08.25_18.04.00.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### **Нажмите "+ Создать"; укажите стадию, на которой должен срабатывать робот; из списка меню выберите "Другие роботы" и нажмите "Добавить" напротив «\[OLChat] \[Группы] Отправить геометку».**

<figure><img src="../../.gitbook/assets/Скриншот 27.08.25_19.39.15.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Настройте робота, указав группу. в которую будет отправляться геометка, а также введя координаты точки на карте. В поле "Адрес" можно указать название места или улицу, дом. Во второй строке адреса, например, можно указать город. Затем сохраните настройки.

<figure><img src="../../.gitbook/assets/Скриншот 27.08.25_19.43.25.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Поля "Адрес места" не являются обязательными к заполению.
{% endhint %}
{% endstep %}

{% step %}
#### Настройка робота завершена.

В чате открытой линии, связанной с  группой, отправленная роботом геометка будет выглядеть так:

<figure><img src="../../.gitbook/assets/Скриншот 27.08.25_19.50.16.png" alt=""><figcaption></figcaption></figure>

В чате WhatsApp сообщение с геометкой будет иметь следующий вид:

<figure><img src="../../.gitbook/assets/image (1).png" alt="" width="375"><figcaption></figcaption></figure>


{% endstep %}
{% endstepper %}
