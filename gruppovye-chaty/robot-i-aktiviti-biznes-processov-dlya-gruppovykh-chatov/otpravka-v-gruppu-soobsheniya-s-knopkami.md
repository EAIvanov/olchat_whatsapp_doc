# Отправка в группу сообщения с кнопками

Робот «**\[OLChat] \[Группы] Отправить сообщение с кнопками**» позволяет создавать автоматизированные сценарии для отправки сообщения с кнопками ответов, возвращаемых в чат, в подключенные группы при переходе лида или сделки в определённый статус.

Для добавления робота необходимо:

{% stepper %}
{% step %}
#### Перейти в раздел "Роботы" из списка лидов, либо карточки лида в CRM.

<figure><img src="../../.gitbook/assets/image (3) (1) (1) (1).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/image (4) (1) (1).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Добавьте робота.

1. Нажмите "+ Создать";&#x20;
2. Укажите стадию, на которой должен срабатывать робот;&#x20;
3. Из списка меню выберите "Другие роботы";
4. Нажмите "Добавить" напротив «**\[OLChat] \[Группы] Отправить сообщение с кнопками**».

<figure><img src="../../.gitbook/assets/Скриншот 28.08.25_23.34.10.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Настройте робота.

1. Укажите группу, в которую планируется отправка роботом сообщения с кнопками.
2. Введите заголовок сообщения. В данном поле содержится ограничение в 60 символов.
3. Введите текст основного сообщения в поле "Сообщение".
4. Введите подпись к сообщению при необходимости. В данном поле содержится ограничение в 60 символов.
5. Введите содержание кнопок. В данном поле содержится ограничение в 25 символов для каждой кнопки, также с одним сообщением могут быть отправлены максимум 3 кнопки.
6. Сохраните настройки.

<figure><img src="../../.gitbook/assets/Скриншот 28.08.25_23.36.45.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Настройка робота завершена.

{% endstep %}
