# Отправка голосового сообщения в группу

Робот «**\[OLChat] \[Группы] Отправить голосовое сообщение**» позволяет создавать автоматизированные сценарии для отправки голосового сообщения в подключенные группы при переходе лида или сделки в определённый статус.

Для добавления робота необходимо:

{% stepper %}
{% step %}
#### **Записать планируемое к отправке роботом голосовое сообщение.**

Это можно сделать, например, в личных заметках на портале Битрикс24, а затем сохранить записанное сообщение на Битрикс.Диске с помощью контекстного меню. Сохранить на Битрикс.Диск можно любое голосовое сообщение из личных чатов и открытых линий портала, либо загрузить голосовое сообщение аудиофайлом. Еще один вариант - получить прямую ссылку на аудиофайл с голосовым сообщением.

{% hint style="info" %}
Для корректной работы робота рекомендуем использовать аудиофайлы с форматом mp3.

Голосовые сообщения на портале Битрикс24 сохраняются на Диск в формате mp3.
{% endhint %}
{% endstep %}

{% step %}
#### Добавляем робота: необходимо перейти в раздел "Роботы" из списка лидов, либо карточки лида в CRM.

<figure><img src="../../.gitbook/assets/Скриншот 27.08.25_18.03.16.png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/Скриншот 27.08.25_18.04.00.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### **Нажмите "+ Создать"; укажите стадию, на которой должен срабатывать робот; из списка меню выберите "Другие роботы" и нажмите "Добавить" напротив «\[OLChat] \[Группы] Отправить голосовое сообщение».**

<figure><img src="../../.gitbook/assets/Скриншот 27.08.25_20.52.54.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Настройте робота, указав группу, в которую будет отправляться голосовое сообщение, затем выберите из выпадающего списка тип источника файла, далее, в зависимости от выбранного типа источника, укажите ссылку или ID на аудиофайл с голосовым сообщением.

Тип источника файла может быть:

* Прямая ссылка на файл;
* Битрикс24.Диск;
* Файл из поля CRM;
* Короткая ссылка Битрикс24.

В данном примере голосовое сообщение сохранено на Битрикс.Диске портала, поэтому в соответствующем поле удобнее будет указать ID файла.&#x20;

ID файла указан в соответствующем столбце строки необходимого файла на Битрикс.Диске.

<figure><img src="../../.gitbook/assets/Скриншот 27.08.25_21.03.38.png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/Скриншот 27.08.25_20.56.18.png" alt=""><figcaption></figcaption></figure>

Сохраните настройки робота.
{% endstep %}

{% step %}
#### Настройка робота завершена.
