# Отправка в группу сообщения с шаблонными кнопками

Робот «**\[OLChat] \[Группы] Отправить сообщение с шаблонными кнопками**» позволяет создавать автоматизированные сценарии для отправки сообщения с шаблонными кнопками в подключенные группы при переходе лида или сделки в определённый статус. Данные кнопки могут содержать, например, промокод, ссылку на чат с поддержкой, контактный телефон.

Для добавления робота необходимо:

{% stepper %}
{% step %}
**Перейти в раздел "Роботы" из списка лидов, либо карточки лида в CRM.**

{% step %}
#### Добавьте робота.

1. Нажмите "+ Создать";&#x20;
2. Укажите стадию, на которой должен срабатывать робот;&#x20;
3. Из списка меню выберите "Другие роботы";
4. Нажмите "Добавить" напротив «**\[OLChat] \[Группы] Отправить сообщение с шаблонными кнопками**».

<figure><img src="../../.gitbook/assets/Скриншот 28.08.25_23.49.57.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Настройте робота.

1. Укажите группу, в которую планируется отправка роботом сообщения с кнопками.
2. Введите заголовок сообщения. В данном поле содержится ограничение в 60 символов.
3. Введите текст основного сообщения в поле "Сообщение".
4. Введите подпись к сообщению при необходимости. В данном поле содержится ограничение в 60 символов.
5. Настройте кнопки. Выберите тип каждой из кнопок: Копирование текста, Внешняя ссылка, Кнопка звонка. Заполните поля "Текст" содержанием кнопок и задайте параметры каждой из них. Чтобы подставить автоматические параметры с данными из персонализированных CRM-форм, нажмите на троеточие в конце строки параметра и выберите соответствующий параметр. В данном поле содержится ограничение в 25 символов для каждой кнопки, также с одним сообщением могут быть отправлены максимум 3 кнопки.&#x20;
6. Сохраните настройки.
